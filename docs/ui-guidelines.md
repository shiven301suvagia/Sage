# UI Guidelines

The Sage interface should communicate intelligence through clarity, restraint, and responsiveness. Visual design should support focus rather than compete for attention.

## Principles

- Prioritize legibility, predictable layout, and accessible contrast.
- Make system state visible through calm status indicators.
- Use animation and visual emphasis to explain change, not decorate it.
- Keep high-risk actions visually distinct and confirmation-driven.
- Preserve user control through settings, history, and clear cancellation paths.

## Core Surfaces

- Conversation: the primary space for natural language interaction and structured results.
- Command Palette: fast access to actions, plugins, settings, and workflows.
- Activity Panel: transparent view of running tasks, tool calls, and pending confirmations.
- Memory and Privacy Settings: user-facing controls for persistence, deletion, and data scope.
- Plugin Manager: installation, permissions, status, and compatibility information.

## Accessibility

All primary workflows should be keyboard navigable, screen-reader compatible, and usable without relying on color alone. Motion should respect reduced-motion preferences.
