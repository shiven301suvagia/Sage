# Animation Guide

Animation in Sage should make the assistant feel responsive and understandable without becoming distracting. Motion is a communication tool, not a personality substitute.

## Motion Principles

- Use short, smooth transitions for state changes.
- Prefer subtle easing over dramatic movement.
- Avoid continuous animation unless it communicates active processing.
- Respect operating system reduced-motion settings.
- Keep animation performance within desktop application budgets.

## Interaction States

- Idle: minimal ambient presence with no unnecessary motion.
- Listening or Input Active: clear but restrained focus indication.
- Thinking: gentle progress feedback that does not imply exact timing.
- Acting: visible task state with cancellation or pause controls when possible.
- Complete: brief confirmation that preserves workflow momentum.
- Error: calm, noticeable feedback with a recovery path.
