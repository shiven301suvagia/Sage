# SAGE Product Documentation

This directory is the canonical product-development documentation set for SAGE, the desktop AI companion.

## Document set

1. [Product Requirements Document](./PRD.md) - product vision, users, scope, outcomes, principles, and acceptance criteria.
2. [Requirements Specification](./REQUIREMENTS.md) - functional, non-functional, security, privacy, accessibility, and quality requirements.
3. [Architecture Specification](./ARCHITECTURE.md) - system boundaries, components, data flows, interfaces, security boundaries, and deployment model.
4. [UI/UX Specification](./UI-UX.md) - visual language, interaction model, states, flows, accessibility, and desktop behavior.
5. [Development Plan](./DEVELOPMENT-PLAN.md) - delivery phases, workstreams, milestones, testing strategy, release gates, and definition of done.

## Source of truth

These documents refine and formalize the existing repository vision, roadmap, non-negotiables, personality, animation, API, and implementation structure. They are intended to remain aligned with code and to be updated through normal pull requests when product or architecture decisions change.

## Product north star

SAGE should feel like a capable companion living on the desktop: calm when idle, attentive when needed, useful in ordinary conversation, and trustworthy when performing actions. Intelligence is only successful when paired with user control, privacy, recoverability, and a polished human-centered experience.

## Status vocabulary

- **MUST** - release-blocking requirement.
- **SHOULD** - important requirement that may be deferred only with an explicit decision.
- **MAY** - optional enhancement.
- **TARGET** - intended future behavior, not a claim that the current implementation already provides it.
